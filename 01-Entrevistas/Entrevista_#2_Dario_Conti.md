# Relevamiento de Requerimientos - Stock Proyect

**Entrevistado:** Darío Fabián Conti  
**Contexto:** Distribuidora de productos capilares  

---

## 1. Objetivo del Software
El software busca automatizar el control de stock y ventas que actualmente se realiza de forma manual.

## 2. Necesidades Principales
* **Control Activo:** Gestión de stock y ventas con alertas (push) ante niveles bajos de productos.
* **Seguimiento:** Mejorar la velocidad y trazabilidad de los pedidos.
* **Listas de Precios:** Generación automatizada de listas de precios.

## 3. Restricciones y Usuarios
* **Uso:** El software es exclusivamente para uso interno de la distribuidora.
* **Usuarios:** Se definen dos perfiles de acceso:
    * **Administrador:** Acceso total sin restricciones.
    * **Empleado:** Funciones limitadas.
* **Seguridad:** Restricción de permisos para modificar precios, balances y control de stock según el tipo de usuario.

## 4. Detalles Técnicos
* **Puntos de Venta:** Un único local.
* **Integraciones:** Posible enlace con el laboratorio (opcional, no crítico).
* **Estado Actual:** Los datos se manejan en papel y los precios en una hoja de cálculo de Google.

## 5. Proyecciones
* Agilizar procesos de venta y creación de listas de precios.
* Establecer un control de stock sólido.
